# D3D12 declared-resource binding validation, 2026-11-08

This incremental change retains the custom fork delivered in GooseHUB 0.2.9. Replacing only src/d3d12/d3d12.cpp with the pre-task snapshot reconstructs `b0c464ca38960d1a3721f0dfddd2e02ac3910d8a412a5b50536843d8fe11fa20` exactly. The new source digest is `ee3ec3944fcf8b1d14c45c98e31c43d3129c9c33930e3ccef50d9ba3f78a4d5d`. D3D11, D3D9, DXGI, native winemetal, Wine and FEX are unchanged.

DXBC pipeline creation now caches the shared shader converter's CBV, SRV, sampler and UAV masks for vertex, pixel, geometry and compute stages. Replay resolves and retains only descriptors declared for the visible stage. It also skips unused GPU-address lookups, root-constant uploads and static sampler bindings. A missing shader has no inputs; unavailable reflection conservatively retains all slots. Descriptor contents are still read at execution, including volatile tables, and the existing compute UAV handoff remains intact. Native SM6 execution is unchanged. No game names, visual settings, frame limits or fake query results are used.

The [D3D12 descriptor table rules](https://learn.microsoft.com/en-us/windows/win32/direct3d12/advanced-use-of-descriptor-tables) allow unreferenced entries to change independently. This change avoids touching entries absent from shader declaration reflection; it does not attempt to infer runtime branch decisions.

All 23 validation modes passed on ARM64EC, x64 and x86: 69 successful runs. The GPU outputs cover both ends of a 128-slot texture range (t0/t127), sampler s15, CBV/root-CBV/root-constants at b13, stage visibility, geometry shaders, compute skin cache, overlapping UAVs, aliasing, descriptor updates after recording, depth/MRT copies, command-list snapshots, first-draw compilation and actual query values. Nine additional checks against the packaged Wine/DXMT engines also passed on the three architectures. Existing broader API validation is recorded in [the previous release](../d3d12/README.md).

Three interleaved comparisons each submitted 1,025 actual draws with a 64-entry texture table and 16 sampler descriptors. The last four of six iterations in each run gave a median CPU submission time of 1.37875 ms before and 0.48145 ms after (65.08% lower). Completion of the GPU work changed from 2.51540 ms to 1.55985 ms. These are isolated bridge measurements, not game FPS or a claim of D3D11 parity.

The automatic Severed Steel workload also ran 4,856 successful presents with normal skin cache and occlusion, without skipped pipeline draws or fatal device/query errors. The recent uncontrolled present interval was 15.81 ms, compared with 17.72 ms in an earlier automatic run; foreground state and moving-scene workload were not matched, so those intervals are not a valid FPS A/B result. Fresh visual confirmation is tracked separately. Proprietary game shaders, captures, saves and process environment snapshots are excluded.
